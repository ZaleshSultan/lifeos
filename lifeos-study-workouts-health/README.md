# Обновление: учёба, тренировки и часы

Обновление рассчитано на состояние после `lifeos-all-grades-fix.patch`.
Миграция базы не нужна. Код и APK проверены локально; установка на сервер и
проверка Health Connect на телефоне выполняются отдельно.

## Что добавлено

- Раздел «Учёба»: недельное расписание, калькулятор и все текущие оценки Moodle.
- Импорт 25 занятий и схем расчёта пяти предметов из предоставленного HTML.
  Ранее установленные связи с курсами Moodle сохраняются.
- Калькулятор сохраняет отдельный сценарий по предмету. Пустое поле означает
  неизвестный балл, ноль — полученный ноль. Формула: 30% + 30% + 40%.
  Оценки Moodle не подставляются в компоненты автоматически: их соответствие
  лабораторным и контрольным в учебном плане ещё не установлено.
- Тренировки: программа с именованными днями, выбор дня, фактические повторы,
  вес и отдых, отмена подхода, история последних 50 тренировок и прогресс.
- Health Bridge: пульс покоя из отдельной записи, HRV, корректная обработка
  стадий сна, чтение всех страниц Health Connect. Пропуски не заменяются нулями
  или средним пульсом. Повторная отправка обновляет измерения без дубликатов.
- Подключение Health Bridge из раздела «Здоровье» миниприложения.

## Установка сервера

Сохрани архив `lifeos-study-workouts-health.zip` в `~/lifeos`.
Архив содержит патч, исходный `расписание.html`, инструкцию и отладочный APK.

```bash
cd ~/lifeos &&
unzip lifeos-study-workouts-health.zip &&
git apply --check ./lifeos-study-workouts-health/lifeos-study-workouts-health.patch &&
git apply ./lifeos-study-workouts-health/lifeos-study-workouts-health.patch &&
pnpm typecheck &&
pnpm test:all &&
LIFEOS_ENABLE_LEGACY_SINGLE_USER_UNIVERSITY_SYNC=true \
  workers/university-sync/aitu-parser/.venv/bin/python \
  scripts/import_study_dashboard.py \
  --html './lifeos-study-workouts-health/расписание.html' --apply &&
bash scripts/build-tma-selfhost.sh &&
sudo systemctl restart lifeos-bot
```

Импорт использует существующий `workers/university-sync/aitu-parser/.env` и
`LIFEOS_DEFAULT_USER_ID`. Moodle-cookie для него не нужен. Полный предварительный
просмотр изменений доступен той же командой без `--apply`.

Если команда остановилась после применения патча, продолжи с неудавшегося шага:
повторно применять патч не нужно. Импорт можно повторять, он сохраняет уже
внесённые сценарии и не создаёт одинаковые занятия повторно. Не добавляй архив,
распакованную папку и персональный HTML в Git.

После установки закрой и снова открой миниприложение. В разделе «Учёба» должны
появиться пять предметов и 25 занятий; число оценок берётся из текущей базы.
Для калькулятора введи баллы и нажми «Сохранить сценарий». Для тренировок открой
«Программа», настрой дни, сохрани и выбери день перед началом занятия.

## Установка на Samsung Galaxy S23+

1. Скопируй `lifeos-health-bridge-debug.apk` из архива на телефон и установи.
   Это отладочная сборка, без встроенных учётных данных. Если Android сообщает
   о несовпадении подписи с прежней сборкой, собери APK из обновлённого проекта
   своим прежним ключом; инструкция находится в `apps/health-bridge/README.md`.
2. В миниприложении открой «Здоровье» и блок подключения Health Bridge.
   Получи токен по кнопке, перенеси адрес API и токен в приложение на телефоне.
   Токен действует 30 дней; после истечения получи новый тем же способом.
   Если сервер сообщает, что выдача токена не настроена, настрой существующую
   переменную `LIFEOS_HEALTH_INGEST_JWT_SECRET` в окружении бота и перезапусти его.
   Настроенный секрет менять не требуется.
3. В Health Connect проверь, что Mi Fitness записывает данные, а LifeOS Health
   Bridge может их читать. Разреши чтение пульса покоя — это новое разрешение.
4. В Health Bridge сохрани настройки и нажми **Sync now**. Для первой проверки
   оставь приложение открытым. Оно отправляет данные **за предыдущий день**
   по часовому поясу телефона.
5. Обнови раздел «Здоровье» в миниприложении. Статус также доступен через
   `/health` и `/sync health` в боте.

Если Mi Fitness не передаёт определённый показатель в Health Connect, LifeOS
оставляет его неизвестным. Наличие HRV, пульса покоя и стадий сна нужно проверить
на телефоне. Автоматический фоновый запуск пока не подтверждён на Galaxy S23+;
в этой версии проверяется ручная синхронизация, разрешение фонового чтения
Health Connect ещё не реализовано.
