Refreshing a token alone leaves established connections active. This work requires operational authorization because it can interrupt connectivity.

Remaining product limits are explicit: the supported reviewed forecast policy is linear 30/30/40, the latest history view is bounded to 100 events, failed/unconsumed snapshot backlog needs operational monitoring, and unsupported academic rules remain conditional. A current source/enrollment review is required for policy confirmation; known course-date bounds must contain the campus day, while null bounds are permitted after explicit owner review. Unknown observations stay unknown even when the policy is confirmed. Stale/expired Moodle access is reported unavailable; this task did not reconnect or independently verify the owner's live LMS. Work links retain course context but open the existing unfiltered list. Arbitrary historical workout-detail selection is not added merely because navigation retains a `workoutId`.
